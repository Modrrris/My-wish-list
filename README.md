# My Wish List

A public list of problems I want solved, with a link to the tool I build for each one.

## Add or edit a wish

Edit [`_data/wishes.yml`](_data/wishes.yml) (the pencil icon on GitHub works fine from a phone):

```yaml
- title: Short name of the wish
  description: One sentence about it.
  status: idea        # idea | building | live
  tool: https://...   # add once the tool exists
```

Commit to `main` and the site updates in about a minute.

## Change the title or intro

Edit `_config.yml`.
